# Changelog

All notable changes to Affixa are documented here.
Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- New logo: calligraphic "A" mark (gold leg, sage blade crossbar, teal
  hook, diamond sparkle) on the deep-green badge, generated by
  `tools/gen-logo.mjs` and served as the shared `/logo.svg` asset used
  by the NavBar, sidebar, landing footer and favicon.
- `/api/health` liveness endpoint.
- Pytest suite (`backend/tests`) covering health routes, the analyzer
  pipeline, tokenizer behaviour and the analyze/compare REST contracts.
- `ErrorBoundary` with a friendly fallback instead of a blank screen.
- Route-level code splitting: three.js loads only on auth pages, recharts
  only on Analytics/Batch.
- Accessibility: skip-to-content link, keyboard focus ring,
  `prefers-reduced-motion` support, aria labels for icon-only controls,
  autocomplete hints on auth forms.
- Route-aware `document.title`, SEO/Open Graph meta tags.
- Docs: `docs/ARCHITECTURE.md`, `docs/API.md`, `docs/TESTING.md`,
  `docs/DEPLOYMENT.md`, `CONTRIBUTING.md`, `LICENSE`, `.env.example`
  files, `.editorconfig`.
- CI workflow running backend tests and the frontend type-check/build.

### Fixed

- Core features failing with 404: API base URL now targets
  `127.0.0.1:8000` because `localhost` resolved to IPv6 `::1` where
  WSL/Docker services hold port 8000.
- `Comparison.tsx` called a nonexistent `/compare/word` route before
  falling back; it now calls `POST /api/compare` directly.
- Auth pages showed the logo twice (NavBar plus left-panel header); the
  left panel now carries only a subtle eyebrow line.
- `POST /api/analyze/word|text` and `/api/compare` rejected
  whitespace-only input incorrectly (returned 200 with junk results).
- README API reference described `/api/compare/word` and `GET
  /api/affixes`, neither of which exists.

## [0.1.0] — initial release

### Added

- Rule-based morphological analyzer: longest-match affix stripping,
  12 morphophonological restoration rules, WordNet validation,
  calibrated confidence scoring.
- Dashboard pages: Analyzer, Batch processor, Comparison benchmark,
  Analytics, Dictionary, Settings with API playground.
- Supabase auth with optional TOTP two-factor, Forgot Password flow,
  protected routes and command palette (`Ctrl/Cmd+K`).
- Forest Green design system with dark/light modes, 3D split-screen
  auth panels, landing page.
